# js-firts

# Clases y Prácticas de JavaScript

## Descripción del Proyecto
Repositorio dedicado al aprendizaje, desarrollo y práctica de JavaScript aplicado al desarrollo web frontend. Contiene una colección de ejercicios, talleres y proyectos estructurados que integran marcado semántico (HTML5), estilos visuales (CSS3) y lógica de programación interactiva (JavaScript).

## Estructura del Repositorio
*   **HTML:** Estructuras base y formularios interactivos para la manipulación del DOM.
*   **CSS:** Hojas de estilo para maquetación, diseño responsivo y efectos visuales.
*   **JavaScript:** Scripts enfocados en lógica de programación, eventos, manipulación de elementos del DOM, consumo de datos y resolución de problemas algorítmicos.

## Tecnologías Utilizadas
*   JavaScript (ES6+)
*   HTML5
*   CSS3
*   Git y GitHub
